# ХимСтарт Website

## Setup
1. Install dependencies: `pip install flask flask-wtf email-validator`
2. Update email settings in app.py
3. Place logo.png in app/static/images/
4. Run: `python app.py`

## Pages
- / : Home
- /about : About Us
- /products
- /methodology
- /faq
- /contact

Contact form sends email (configure SMTP).
